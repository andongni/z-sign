# 测试数据说明

后端已迁移为 FastAPI，旧的 Django 管理命令 `fill_test_data` 已移除。

当前可用的后端管理命令：

```bash
cd backend
python manage.py init-db
python manage.py create-admin --username admin --email admin@example.com --password admin123
```

如果需要批量测试数据，建议基于 `backend/app/models.py` 和 `SessionLocal` 编写新的 FastAPI/SQLAlchemy seed 脚本。
